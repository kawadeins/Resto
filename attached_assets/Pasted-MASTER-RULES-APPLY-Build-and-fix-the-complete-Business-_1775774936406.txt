4. SESSION INTEGRATION
========================

Both Google and Apple sign-in must end in the same secure business session system already used by the platform.

Requirements:
- create server-side session after successful auth
- set correct secure cookie behavior
- keep role-based access working
- make dashboard requests authenticated immediately after login
- do NOT rely on localStorage hacks for identity

========================
5. ACCOUNT MATCHING / BUSINESS RESOLUTION
========================

After Google or Apple login, the system must resolve the authenticated business user correctly.

Required behavior:
- if email matches a real owner account → log in as owner
- if email matches an active manager/staff team member → log in with correct role
- if account is unknown → show a clean German message and deny access safely

No accidental auto-owner behavior.
No fake account creation.
No unauthorized access.

========================
6. REDIRECT FLOW
========================

After successful login:
- redirect to the correct business dashboard
- no blank page
- no broken state
- no partial session

- skip login page
