Build a "Behavior Priority Engine (Ranking Brain + Sponsored Boost System)" inside the existing RestoMaster platform.

IMPORTANT:
Do NOT break existing functionality.

Do NOT create fake ranking.
This is the central decision engine for visibility and ranking.

========================
GOAL
========================

Create a unified ranking system that decides:

- which business appears first
- which appears second
- which appears later

Based on:
- user relevance
- context
- behavior
- AND paid boost (budget)

This is the core brain of discovery.

========================
1. CORE RANKING ENGINE (CRITICAL)
========================

Build a scoring system for each place.

Each place gets a dynamic "priority score" based on:

+ location proximity
+ open now status
+ business type relevance (restaurant / café / bar)
+ time of day match
+ user preferences
+ meal plan match
+ rating
+ popularity / activity
+ friend/social signals
+ live activity / heat map

AND:

+ sponsored boost score (if active)

========================
2. SPONSORED BOOST INTEGRATION
========================

Integrate paid boost into the ranking system.

Each business can:
- set daily budget (e.g. 5€, 10€, 20€)
- run campaign (daily / weekly / monthly)

Boost effect:
- increases ranking score
- increases visibility frequency
- increases exposure in:
  - search
  - homepage
  - near you
  - map

BUT:

Boost must NOT override relevance completely.

========================
3. RANKING FORMULA LOGIC
========================

Use weighted scoring:

Final Score =
(relevance score * high weight)
+ (context score)
+ (behavior score)
+ (boost score * controlled weight)

Ensure:
- boost enhances, not dominates
- bad matches cannot rank #1 just by paying

========================
4. FAIRNESS RULES (VERY IMPORTANT)
========================

Never allow:

- closed places ranking high
- very far places ranking high
- irrelevant business types dominating
- low-quality places dominating

Even if boosted.

Relevance always comes first.

========================
5. BOOST BEHAVIOR SYSTEM
========================

Boost should:

- push business higher when relevant
- increase chance of appearing in top positions
- increase frequency of appearance

But not:
- guarantee position #1 always
- break user trust

========================
6. TIME-AWARE BOOSTING
========================

Boost must respect time:

- morning → cafés boosted
- lunch → restaurants boosted
- night → bars boosted

Even if business pays, it must align with time context.
