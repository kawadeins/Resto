========================
4. ISSUE FORMAT (MANDATORY)
========================

For each issue, document:

- Issue title
- Area / system
- Severity
- What is happening
- Why it matters
- User impact
- Suggested fix direction

Example format:

1. Booking confirmation not persisted after refresh
- Area: User booking flow
- Severity: Critical
- Problem: Booking appears successful but disappears after refresh
- Impact: destroys trust and breaks core flow
- Fix direction: verify booking write + fetch path + success state logic
