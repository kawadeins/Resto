========================================
BACKEND (wallet.ts)
========================================

1. Replace any dynamic Stripe product lookup with a fixed mapping:

const WALLET_PRICE_MAP = {
  5: "price_1TK85zDq06OMDnUjwib9ALyb",
  10: "price_1TK86iDq06OMDnUjlGz1JfYl",
  20: "price_1TK87FDq06OMDnUjz3TfwCgI",
  50: "price_1TK88CDq06OMDnUjiu6n5Sx7",
};

2. Validate amount strictly:

- Only allow: 5, 10, 20, 50
- Reject anything else with 400 error

3. Create Stripe Checkout Session:

const priceId = WALLET_PRICE_MAP[amount];

const session = await stripe.checkout.sessions.create({
  mode: "payment",
  payment_method_types: ["card"],
  line_items: [
    {
      price: priceId,
      quantity: 1,
    },
  ],
  success_url: `${APP_URL}/billing?topup=success`,
  cancel_url: `${APP_URL}/billing?topup=cancel`,
  metadata: {
    type: "wallet_topup",
    amount: amount.toString(),
    userId: user.id,
  },
});

4. Return:

return { checkoutUrl: session.url };

========================================
WEBHOOK (IMPORTANT — DO NOT SKIP)
========================================

In webhook handler:

IF event.type === "checkout.session.completed":

- Verify:
  session.payment_status === "paid"
  session.metadata.type === "wallet_topup"

- Then:

const amount = Number(session.metadata.amount);

- Add to wallet balance in DB

- Use idempotency (do NOT double credit)
